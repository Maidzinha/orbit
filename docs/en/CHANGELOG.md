# Changelog — Orbit

[Português](../../CHANGELOG.md) · **English**

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow `MAJOR.MINOR.PATCH`.

## [1.0.0] — 2026-11-06

First release.

- Tracks the foreground app every second, storing only the program name and the time.
- Smart idle detection: stops counting after 2 minutes without mouse or keyboard input (configurable), but keeps counting with a fullscreen window. A locked screen and sleep never count.
- **Today**, **Week** and **Month** screens with app ranking, charts by hour and by day, Boss of the day and day streak.
- App details screen: last 14 days, busiest hours, total and level.
- Per-app levels, achievements (Marathoner, Night Owl, Early Bird, Explorer, Balanced) and a daily goal.
- Original mascot **Luna**, with four moods.
- English and Portuguese (Brazil); Neon dark, Light and Black & pink themes.
- System tray, start with Windows, CSV export, ignored apps and history deletion.
- Installer and portable version for Windows 10/11 64-bit.
